# 📝 To-Do List

A modern and responsive To-Do List web application built with **HTML**, **CSS**, and **JavaScript**. The application enables users to efficiently manage daily tasks with automatic data persistence using the **Local Storage API**, ensuring tasks remain available even after the browser is refreshed or reopened.

## ✨ Features
- Add new tasks
- Delete existing tasks
- Automatic task persistence using Local Storage
- Data retention after page refresh
- Responsive and user-friendly interface
- Clean blue-themed design with a custom favicon

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript (ES6)
- DOM Manipulation
- Local Storage API

## 🚀 Getting Started
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Start managing your tasks.
